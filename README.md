# tampermonkey-scripts

A collection of fun [Tampermonkey](https://www.tampermonkey.net/) userscripts.

## Scripts

### 🎉 Konami Party Mode [`scripts/konami-party.js`](scripts/konami-party.js)

Enter the legendary **Konami Code** on any website to unleash party mode!

**How to activate:** Press `↑ ↑ ↓ ↓ ← → ← → B A` on your keyboard.

- A festive banner pops up in the centre of the screen
- Emoji confetti rains down from the top of the page 🎊🦄🌈
- Everything cleans up automatically after 5 seconds
- Press the code again mid-party to stop it early

**Installation:**
1. Install the [Tampermonkey](https://www.tampermonkey.net/) browser extension.
2. Click **Create a new script** in the Tampermonkey dashboard.
3. Paste the contents of [`scripts/konami-party.js`](scripts/konami-party.js) and save.
4. Visit any website and type the Konami Code! 🕹️
